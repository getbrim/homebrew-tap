# Homebrew tap for Brim

```sh
brew install --cask getbrim/tap/brim
```

Brim is a free notch app for macOS 15+ on Apple Silicon: your next meeting, Now Playing, a timer, a file shelf, a screen recorder and Claude Code sessions and limits. Website: https://brim-ehw.pages.dev/?ref=homebrew · Releases and issues: https://github.com/getbrim/brim-releases

The cask also links the `brim` command-line tool. Brim updates itself; `brew upgrade --cask brim` works too.
